## What it does

`main.py` (Python 3.13, standard library only, no network) writes one
original single-line office joke to `/output/entry.txt`:

> I asked the printer for one copy of my resignation, and it printed twelve — now the whole floor knows before my boss does.

The joke is written deterministically — the same bytes on every run — and
is 122 characters, within the 1–200 character limit.

## Run

```sh
python3 main.py
```
